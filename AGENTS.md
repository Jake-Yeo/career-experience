# Career Experience Archive

Private local site for preserving Jake's work history and preparing accurate interview stories.

## Stack

- React 19 and TypeScript
- Vite
- Lucide icons
- npm with `package-lock.json`

## Commands

- `npm run dev`
- `npm run build`
- `npm run lint`

## Content rules

- Keep confirmed facts separate from details Jake still needs to clarify.
- Never invent metrics, technical architecture, job responsibilities, or business outcomes.
- Preserve useful technical depth for interview preparation; public portfolio copy can be distilled later.
- Do not publish or deploy this private archive unless Jake explicitly asks.
